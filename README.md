## 3. Реализация перцептрона

### 3.1 Архитектура

Модель представляет собой однослойный перцептрон с одним нейроном. Для входного вектора `x = (x1, x2)` вычисляется линейная комбинация:
\[
z = w_1 x_1 + w_2 x_2 + b
\]
где `w = (w1, w2)` — вектор весов, `b` — смещение.

### 3.2 Функция активации (сигмоида)

Для получения вероятности принадлежности к классу 1 применяется сигмоидная функция:
\[
\sigma(z) = \frac{1}{1 + e^{-z}}
\]
Она отображает произвольное вещественное число в интервал (0,1), что позволяет интерпретировать выход как вероятность.

**Численная стабильность (клиппинг):**  
При больших по модулю значениях `z` (например, при неудачной инициализации или большом шаге обучения) вычисление `exp(-z)` может привести к переполнению типа `float64`, порождая `inf` или `NaN`. Чтобы избежать этого, аргумент `z` обрезается (`np.clip`) в диапазон `[-250, 250]`. Границы выбраны с запасом: `exp(250) ≈ 10^108`, что далеко от предела `10^308`. При `z = ±250` сигмоида уже насыщена (практически 1 или 0), и дальнейшее увеличение `z` не изменяет выход, поэтому клиппинг не влияет на нормальную работу модели.

### 3.3 Прямой проход

Метод `forward(X)` вычисляет `z = X·w + b` для всех примеров в матрице `X`. В режиме BCE применяет сигмоиду, возвращая вероятности. В режиме Hinge loss возвращает сырые логиты `z`.

### 3.4 Функция потерь

**Бинарная кросс-энтропия (BCE):**
\[
L = -\frac{1}{m}\sum_{i=1}^m \big[ y_i \ln(\hat{y}_i) + (1 - y_i) \ln(1 - \hat{y}_i) \big]
\]
В коде предусмотрена защита логарифма: `y_pred` обрезается в `[ε, 1-ε]`, где `ε = 1e-15`, чтобы избежать `log(0)`.

**Hinge loss (для доп. задания):**
\[
L = \frac{1}{m}\sum_{i=1}^m \max(0, 1 - y_i^{(h)} z_i)
\]
где `y_i^{(h)} = +1` для класса 1, `-1` для класса 0.

**L2-регуляризация:**  
К функции потерь добавляется штраф `(λ/2)·||w||²`, что заставляет веса стремиться к нулю и предотвращает переобучение.

### 3.5 Обратное распространение и обновление весов

Градиенты вычисляются аналитически (для BCE):
\[
\frac{\partial L}{\partial z_i} = \hat{y}_i - y_i
\]
\[
\frac{\partial L}{\partial w} = \frac{1}{m} X^T (\hat{y} - y) + \lambda w
\]
\[
\frac{\partial L}{\partial b} = \frac{1}{m} \sum_{i=1}^m (\hat{y}_i - y_i)
\]

Обновление параметров выполняется методом **мини-пакетного градиентного спуска (SGD)**:
\[
w \leftarrow w - \eta \frac{\partial L}{\partial w}, \quad b \leftarrow b - \eta \frac{\partial L}{\partial b}
\]

Для **momentum** добавлено накопление скорости:
\[
v_w = \beta v_w + (1-\beta)\frac{\partial L}{\partial w}, \quad w \leftarrow w - \eta v_w
\]
Аналогично для смещения.

### 3.6 Метрики качества

Реализованы с нуля:
- Accuracy — доля правильных ответов.
- Precision — `TP / (TP + FP)`.
- Recall — `TP / (TP + FN)`.
- F1-score — гармоническое среднее Precision и Recall.
- ROC-AUC — площадь под кривой ошибок. Вычисляется методом трапеций после сортировки примеров по убыванию вероятностей.
